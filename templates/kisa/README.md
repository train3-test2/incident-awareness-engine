# 제공된 KISA 신고서 원본

사용자가 직접 제공한 두 파일이다. 렌더러는 원본을 읽기만 하고 출력용 복사본의
`word/document.xml`만 채운다. 사용자가 제공한 파일이라는 출처와 실제 기관이 배포하는
최신 공식 서식이라는 별도 검증은 구분한다.

| 원본 | 크기 | SHA-256 |
|---|---:|---|
| KISA_침해사고_신고서.docx | 92,113 bytes | `191da8b91ecf311070a5d9479fbef38f28245a6eba2df9781ad4694d4bdeac78` |
| KISA_침해사고_신고서.hwp | 135,168 bytes | `c5b711439f3c567a34ac1e79bcc331d552e9b58d7c2c3f12419a913f01e05c8f` |

DOCX에는 공통 안내·동의와 랜섬웨어/DDoS/그 밖의 해킹 표가 있다. HWP는 항목 대조에만
사용했다. HWP 출력·변환 및 두 파일의 픽셀 단위 일치는 검증하지 않았다.

새 원본으로 교체하면 SHA 검증에서 생성을 중단한다. 셀 매핑·Word 레이아웃 재검증 후에만
승인 해시를 갱신해야 한다. 기존 저장 문서의 원본·출력 해시는 그대로 유지된다.

구현과 검증 결과: [공식 양식 기반 DOCX 전환](../../docs/kisa-docx-transition.md).
