    인사이트 계측 안내

    최근 처리 관측은 같은 Telemetry 응답의 last_observed_at과 최근성 상태입니다. Event 최초 수신 시각이나 시스템 가동 여부가 아닙니다. 시각은 UTC로 표시합니다. 최근 60초 미관측은 실측 0과 다르며, 부분 관측과 오래된 관측을 구분합니다.

    최장 소요 단계는 선택한 Runtime Execution의 저장된 계측만 비교합니다. 큐 적체량은 계측 미연결이며 SLA 기준도 미설정입니다. current_stage는 병목 근거가 아니고 입력·처리 건수 차이는 SQS 큐 깊이가 아닙니다. Normalization + Evidence 지연을 E2E SLA로 사용하지 않습니다. 실행 완료만으로 모든 시스템이 정상이라고 판단하지 않습니다.

    최장 소요 단계: Stage Timing API의 동일 Execution 내 관측된 종료 invocation만 비교합니다. 재시도는 별도 invocation으로 비교하며 합산하지 않습니다. 동률은 모두 표시합니다. 실행 경로와 필수 단계 완전성·전체 종료는 v1에서 확인할 수 없어 부분 비교로 표시합니다.
