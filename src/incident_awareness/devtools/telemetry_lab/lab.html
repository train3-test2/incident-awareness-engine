DB 식별자 확인 중

기존 S0 유효 Sysmon fixture 2건을 반복 정규화·추출합니다(run_type=attack인 테스트 자료이며 정상 운영 트래픽이 아닙니다). 명령어를 실행하지 않으며 Run/Event/Decision/Evidence 결과는 저장하지 않습니다. 원본 Event 시각은 바꾸지 않고 처리 관측은 현재 UTC로 기록합니다.

각 배치의 Execution은 새 identity입니다. 저장 재전송은 절대 카운터/revision 계약으로 멱등 처리합니다. 최대 활성 180초·720배치·1,440건. 기본 저속입니다. 중단 후 보고가 오래됨/미관측으로 바뀌는 것이 정상입니다.

첫 배치는 수락 후 다음 실제 초에 처리합니다. 이 입력 대기와 DB I/O는 처리시간 측정 밖입니다. 수락만/완료만 있는 실제 관측 0과, 아무 보고 없는 null 구간을 비교할 수 있습니다.

초기화는 이 격리 DB의 Telemetry 기록만 지웁니다. 기존 개발/S0 DB는 건드리지 않습니다. 새 실험은 시작을 다시 누르세요. 실험 종료 후 DB 삭제 명령은 SETUP.md를 참고하세요.
