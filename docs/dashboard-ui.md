# Runs / Run Detail 화면

API 서버 실행 후 `/dashboard/`에 접속합니다. 별도 Node 빌드 없이 동일 서버에서
HTML/CSS/JavaScript를 제공합니다. PR #121의 API 계약과 구현에 의존합니다.

- 운영자 토큰은 사용자가 입력하며 메모리에만 유지합니다. 새로고침 시 재입력합니다.
- 연결 해제 시 토큰과 조회 내용을 제거합니다. API 데이터는 인증 후 조회합니다.
- 모든 시각은 KST로 표시하고 API의 UTC 값은 변경하지 않습니다.
- Run과 Event 페이지 이동, 명시적 Decision ID 조회, 빈 결과·오류·로딩을 구분합니다.
- 현재 Fast/Fusion 결과와 선택한 Decision은 분리하며 미평가를 미탐지로 바꾸지 않습니다.
- 시스템 판단 시각을 사고 인지 시각으로 사용하지 않습니다.

확인 순서: 서버 접속 → 토큰 입력 → Runs → Run 선택 → Decision ID 조회 → Event 페이지 이동.
잘못된 토큰, 없는 Decision, 서버 연결 실패, 결과 없는 Run도 확인합니다.

후속 범위는 Overview 집계, Decision 이력 선택 목록, Report/LLM 연동입니다.
실제 RDS 및 브라우저 E2E 검증은 별도 환경에서 필요합니다. 공유 운영자 토큰 방식은
개인별 감사·권한 분리를 제공하지 않으므로 배포 인증 방식과 별도로 연결해야 합니다.
