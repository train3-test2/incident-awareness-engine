# Role 2 문서 안내

Role 2는 Evidence 정의·추출, selector 및 approved policy provenance 경계를 담당한다.
해당 계약의 정본은 기존 [Evidence 문서 디렉터리](../../evidence/)에 있으며, 공통 schema는
[결과 계약](../../schema/result-contracts.md)과 [Data Contract v0.2](../../data-contract-v0.2.md)를
참조한다.

역할별 보조 문서가 추가되면 이 디렉터리에 두되, 기존 Evidence 정본을 복제하지 않는다.
